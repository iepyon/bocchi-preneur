| 項目 | 内容 |

| 意思決定ログ | [decisions/](decisions/)（3件。プラグインの対象・ゴール・説明チェックと意思決定ログの方針。シミュレーション Round 5 の計画で決めたもの） |

企画書の中身は大半が未検証の仮説です。検証の進み具合は、企画書の「未検証の前提と次のアクション」を見てください。
