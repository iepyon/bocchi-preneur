# 承認する部署への聞き取り（15分）

相手：新規企画を担う部署で、新規事業の予算を決める人（誰が決めるかも、この聞き取りで確かめる）。

アイデアを売り込みに行く場ではない。「部署が、どういう事実を見て予算をつけてきたか」を聞く。

1. この部署で、新規事業に予算をつけるかどうかは、誰が、どの場で決めますか。
2. 最後に予算をつけた案件は何でしたか（言える範囲で）。そのとき、何が分かっていたからつけましたか。
3. 逆に、最後に予算をつけなかった案件で、何が足りませんでしたか。
4. 社外の利用者向けの案件で、試作の段階で見せてほしいものは何ですか。（利用者の数、払う意思、市場の大きさ、自社の事業とのつながり など、相手の言葉で）
5. 次に途中経過を見せるとしたら、いつ、どんな場がありますか。

締め（コミット）：「試作品ができたら、15分見てもらう場をもらえますか」

記録は `approver-01.md` に。答えは「」でそのまま残す。ここで聞いた基準から、事業化の印を本人が決める（01-concept.md）。
