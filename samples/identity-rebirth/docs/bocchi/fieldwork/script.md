# 課題検証インタビュー台本（10分）

対象：プロダクト開発に関わる仕事（アジャイルコーチ、スクラムマスター、エンジニア、PM、デザイナーなど）をしていて、AIが入ってきたことで、自分が仕事で大切にしていたことの出番が減った人。5人以上。

- コーチ・スクラムマスターだけで埋めない。ほかの職種から2人以上（`decisions/01` の見直す条件に使う）。
- 自分の会社の人・親しい友人だけで埋めない（埋まったらそう記録する）。
- アイデア（自己開示の準備運動のアプリ）は最後まで話さない。

## 聞く前に必ず伝えること
- 「仕事のやり方の変化について、最近の出来事を教えてほしい。話したくないことは話さなくていいし、いつやめてもいい」
- 録音してよいかを確かめる。
- 相手のつらさに踏み込みすぎない。励ましや助言はしない（聞く場であって、相談に乗る場ではない）。
- 話の途中で強い落ち込み（眠れない、仕事に行けない、消えたい等）が出たら、台本をやめて話を聞くことに切り替え、専門の相談窓口があることを伝える。記録には残さない。

## 質問
1. いまの仕事で、AIを使う場面はどこですか。半年前と比べて、何が変わりましたか。
2. 最後に「これは前は自分の出番だったのに」と感じたのはいつですか。そのとき、どんな場で、何が起きましたか。
3. そのとき、実際にどうしましたか。（黙った／反対した・昔のやり方を主張した／その場を任せた／あとで誰かに話した／何もしなかった）
4. そのことを、そのあと誰かに話しましたか。誰に、どんな場で（飲み会、1on1、ふりかえり、コミュニティ、家族）。話さなかったなら、なぜですか。
5. 話した場で、何が起きましたか。言えたこと・言えなかったことはありますか。
6. この半年で、この変化に向き合うために使ったお金や時間はありますか。（講座、本、コーチング、勉強会や懇親会、コミュニティ）
7. ChatGPT や Claude に、このことを話したことはありますか。どうでしたか。
8. このことを、ひとりで考えて整理しようとしたことはありますか。そのとき何を使いましたか（日記、メモ、散歩、AIとの対話など）。何が役に立ち、何が邪魔でしたか。

## 締め（コミット）
- 「同じように、AIで仕事の出番が変わった人を1人紹介してもらえますか」
- 「3週間後にできる試作品を、30分触ってもらえますか」

## やってはいけない質問
- 「こういうアプリがあったら使いますか」
- 「このアイデアどう思いますか」
- 「いくらなら払いますか」
- 「自信を失っていますか」（答えを誘導する。起きた出来事を聞く）
