# ADR-006: 喪失の地図の断片は、画面の側で本人の言葉に含まれるかを確かめる

**状態:** 採用
**日付:** 2026-11-22
**決めた人:** AI（想定の会話で見つけ、直した）
**コミット:** 1d318ff（版21）

## 背景
- 黒板の「喪失の地図」は、本人が使った言葉の断片を4つの段（失ったもの／戸惑いと防衛／受け止めたこと／これからの自分）に置いて、自分を一歩引いて見られるようにするもの（戦略の「メタ認知」につながる）
- 想定の会話で、AIが言い換えた断片、ほかの人のセリフ、文字数制限に合わせて語尾を削った断片が入った。前に置いた断片が入れ替わることもあった
- 指示だけでは、AIがずれることを防ぎきれない

## 決定
- 指示で「相手の発言から連続した部分をそのまま切り出す。言い換えない。相手以外のセリフは入れない。一度入れた断片は消さない」と求める
- そのうえで画面の側で、返ってきた断片を、前に置いた断片と合わせ、空白と句読点を除いて本人が書いた言葉に含まれるものだけを残す（20字まで、各段5つまで）

## 検討した選択肢

### A: 指示だけで守らせる
**良い点:** 簡単
**懸念:** ずれたときに、言い換えが本人の言葉として黒板に出る

### B: 画面の側でも確かめる（採用）
**良い点:** 黒板に出るのは必ず本人が書いた言葉になる
**懸念:** 句読点以外の小さな違い（送り仮名の違いなど）でも捨てられ、段が空のままになることがある

## 結果
- 楽になること：「あなたの言葉で描く」という約束を、画面の側で保証できる
- 難しくなること：AIが少しでも言い換えると断片が消え、地図が進まないように見えることがある
- 見直すこと：本人が触って地図が埋まらないようなら、比べ方をゆるめる
