# ADR（技術の判断の記録）

試作品「喪失と再生の酒場」（`../../prototype/index.html`）の作りについての判断を、1件ずつ残します。

- **意思決定ログ（`../bocchi/decisions/`）との違い**：意思決定ログは、本人が引き受けた事業の判断（誰の課題か、何を入れるか、名前など）です。ADR は、それを試作品でどう実現したかという技術の判断です。事業の判断から来ている ADR には、元の意思決定ログを書きます。
- **決めた人**：技術の判断は、AIが選択肢を示し、本人が選びます（プラグインの絶対ルール2）。本人が選んだもの、本人の依頼を受けてAIが作り方を決めたもの、AIが不具合を直したもの、を分けて書いています。
- **作り方**：2026-11-22 に、git log・意思決定ログ・`03-wireframe.md`・`04-prototype.md`・`prototype/simulation-2026-11-22.md` を読み返して、あとから起こしました。コミットの番号は main に入ったものです。
