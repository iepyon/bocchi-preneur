# ADR-005: マスターの指示は、問い＋言い換えの役、往復の数、落ち込みのサインの扱いを明記する

**状態:** 採用（版21で改訂）
**日付:** 2026-11-22
**決めた人:** AIの役（問い＋言い換え）は本人が仮決めした（選択式）。考えの拠りどころと趣旨は本人の言葉。指示の文面と改訂はAIが行った
**元の意思決定ログ:** `decisions/04-prototype-data-and-ai-role.md`
**コミット:** e5a4806（版1）、9b36c8a（版5でマスターの口調）、2800e11（版8で場面から思い出す）、f3b4869・b699bc1（版13・14で考えの拠りどころ）、1d318ff（版21で改訂）

## 背景
- 本人が汎用AIの弱点に挙げたのは「一般論の励ましで終わり、自分の物語として腹落ちしない」こと
- 本人の考えの拠りどころ：異なる他者のあいだで言葉を交わす「活動」の前に、まず「私と私自身との声のない対話」をする
- 想定の会話3つ（`prototype/simulation-2026-11-22.md`）で、次の問題が見つかった：返事が毎回同じ型で尋問のよう、受け止め・これからに進まない、落ち込みのサインのあと毎回止まる、アプリへの疑問に問いで返す、言い直しを指摘して責めるように聞こえる、物語にマスターの言い回しが混ざる

## 決定（版21の指示の柱）
1. **役**：受け止め（40字以内。1〜2語を置き直すだけでもよい。語尾を変える）＋問い1つ（40字以内）。全体80字前後、上限120字。励まし・助言・評価・AIの解説はしない
2. **進め方**：「# いま」に往復の数を渡す。1〜2往復目は場面、3往復目から失ったもの → 残っているもの、5往復目前後で「次の場で、誰に、どの一言なら」
3. **守り**：言い直しや矛盾を指摘しない。両方を並べて、どちらから話すかを相手に選んでもらう。「人にしかできないことは〇〇だ」が出たら、是非を議論せず、守りたかったものを尋ねる
4. **疑問と短い返事**：アプリへの疑問には1文で答え、一語で答えられる問い（選択肢可）を出す
5. **落ち込みのサイン**：直前の発言にあるときだけ止め、「続けるか、ここで止めるかは、あなたが決めて大丈夫です」と添える。次のターンで再開できる
6. **場面メモ**：選択肢から選んだ場面は、対話と分けて送り、なぞらない
7. **物語と下書き**：材料は相手の言葉だけ。マスターの言葉は使わない。一人称は相手のもの。断定を強めない。字数を満たすために足さない。下書きは「次の企画の場で、上司・ほかの職種の人のうちの誰かに」のように場と相手を決める。防衛的な言葉は「〜と言ってしまった」と書く。体調の話は下書きに入れない

## 検討した選択肢

### A: 問いだけ返す鏡
**良い点:** 言葉が最も本人のものになる
**懸念:** 進まない。短い返事の人が詰まる

### B: 問い＋言い換え（採用。本人の仮決め）
**良い点:** 本人の言葉を確かめながら進められる
**懸念:** 言い換えが長いと、言葉がAIのものになる（字数と型で抑えた）

### C: 伴走して下書きする
**良い点:** 楽
**懸念:** 言葉がAIのものになり、汎用AIとの違いが消える

## 結果
- 楽になること：短い対話でも、受け止めとこれからに少し進める
- 難しくなること：指示が長くなり、入力が大きくなる
- 見直すこと：本人が宿題（AIは対話の中で何をする役で、何をしない役か）に答えたら、合わせ直す（decisions/03 の見直す条件）。実際の返し方は、本人が触って確かめるまで分からない

2. [ ] 課題検証の1人目（アジャイルコーチ）の言葉で、問いの順番を見直す
