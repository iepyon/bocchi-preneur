# サンプル：（名前は未定）AIで大切にしていたことを失った人の、自己開示の準備運動

**本人（このリポジトリの持ち主）が答えて**、プラグインを通しているサンプルです。AIが架空の本人を演じた hitoribi と違い、事業判断はすべて本人の言葉です。途中段階で、進むたびに更新します。

プロダクト開発に関わる仕事をしていて、AIが入ってきたことで、自分が仕事で大切にしていたこと（例：アジャイルコーチのファシリテーション）の出番を失った人が、AIとのひとり対話で喪失を受け入れ、「喪失と再生の物語」と「打ち明けの下書き」を持って、既存の場（飲み会、ふりかえり、1on1、コミュニティ）で周囲に打ち明けられるようにするアプリです。打ち明ける場そのものではなく、その準備運動の場です。

## このサンプルで見てほしいところ

- **最初の像と事実のずれを、その場で直した**：「身動きが取れない人」を想定していたが、事実の人（アジャイルコーチ）は学び始めていた。困りごとを「学んでも前の強みが活きず、すくみ、防衛的になる」に捉え直した（`01-concept.md`）。
- **既存のAIとの違いを2回問い詰めて、「場」と「流れ」にたどり着いた**：一般論の励ましで終わる → 経歴を渡しても足りないのは「ありのまま打ち明ける場」 → 最初の一段は「打ち明ける場そのもの」ではなく「自己開示の準備運動」（`decisions/02`）。
- **広げた対象を、最初の場に招く10人で絞り直した**（`decisions/01`）。
- **企画書は、本人が決めたことと机上調査を分けて書いた**：価格・払う人・事業化の印は本人が決めていないので、論点として並べるにとどめた（`proposal.md`）。
- **分からないことは宿題にした**：承認する部署の期待と事業化の印は、推測で埋めずに聞きに行く（`fieldwork/script-approver.md`）。
