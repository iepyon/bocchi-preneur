# サンプル：ソロプレナー（学習プロダクト）

このプラグイン自身を題材にした企画書です。AI前提で通しきる「ソロ」を育てる学習プロダクト（仮）の企画を、調査から検証計画までまとめています。

| 項目 | 内容 |
|---|---|
| 成果物 | [proposal.md](proposal.md)（企画書） |
| 使ったプラグインの版 | なし（プラグインを通さずに作成。11ステップと6工程の設計のもとになった企画） |
| 相当する工程 | 1 調査、2 企画（検証は計画のみ。未実施） |
| 意思決定ログ | まだない（`decisions/` は、この企画をプラグインで通し直すときに残す） |

企画書の中身は大半が未検証の仮説です。検証の進み具合は、企画書の「未検証の前提と次のアクション」を見てください。
