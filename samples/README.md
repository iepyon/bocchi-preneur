# サンプル

プラグインで実際に通したプロダクトを、サンプルごとにフォルダを分けて置きます。

```
samples/
└── <sample-name>/
    ├── decisions/   # 意思決定ログ（decision-log-template.md を使う）
    └── README.md    # 使ったプラグインの版と工程の記録
```

## 方針

- **意思決定ログを必ず残す**：成果物より、ログのほうがプラグインの価値を示す見本になります。
- **使ったプラグインの版を書く**：プラグインを改良すると、古いサンプルとやり方がずれるためです。
- **人名や出典元の固有名を入れない**：プラグイン本体と同じ方針に揃えます。
- フォルダ名はケバブケースにします。
