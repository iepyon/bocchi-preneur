# サンプル：ひとりび（ソロ同士がゆるくつながる場所）

**架空のプロジェクト**でプラグインを通したシミュレーションです。登場する創業者、インタビュー、数字、見本データはすべて架空です。

ひとりでサービスを作る人が、名前も顔も出さずに、同じ夜に作っている誰かの気配を感じ、短い助言を残し、ときどき少しだけ手を貸し合うWebアプリです。相手と関係を続ける仕組み（フォロー・DM・プロフィール）は、あえて作っていません。

## 4つの仕組み

| 仕組み | すること | ゆるさの理由 |
|---|---|---|
| 灯 | 今日の一手を40字で1つ灯す。他人の灯には言葉なしで「あたる」だけ | 返事を考えなくていい。24時間で消える |
| 書き置き | 11ステップを「場所」として歩き、定型文と語の組み合わせだけで助言を残す | 自由に書けないので、比べ合いも荒らしも起きにくい。14日で風化する |
| 痕跡 | やめた・方向を変えた場所に、学びを3行残す | 名前は出ない。やめることを失敗にしない（プラグインの「やめると決めたら」と同じ形） |
| 救援サイン | 15分か30分だけ助けを求める。応じた1人と期限つきの部屋で話し、しぐさを1つ送って別れる | 連絡先は交換できない。部屋は終了10分後に中身ごと消える |

自分への反応は「残響」に届きます。誰からかは分かりません。

## 試作品の動かし方

```
cd samples/hitoribi/app
node server.js        # Node.js 18 以上。追加のインストールは不要
```

ブラウザで http://localhost:3000 を開きます。2人分を試すには、別のブラウザかシークレットウィンドウでもう1つ開きます。見本データ（架空）は初回起動時に `app/data/db.json` に作られます。作り直すときは `app/data/` を消してください。

## このサンプルで見てほしいところ

- **想定インタビューで進んでも、ゲートは閉じない**：本人が判断を引き受けて先に進んだ記録（`decisions/03-skip-interview-gate.md`）と、ステップ1が「宿題待ち」のまま残っている state.md。
- **UXの5レイヤーの対応表**（v0.9.0 で追加）：戦略のニーズから画面の部品までが1枚の表でつながっている（`02-spec.md` の末尾）。画面を描きながら機能を足したくなったとき、先に要件に戻った記録（`03-wireframe.md` の末尾）。
- **コンテンツの要件で、1人で回せる運営に絞った**：自由記述の見回りを1人で続けられるかを問い詰めた結果、書き置きを定型文だけにした（`decisions/01-template-only-notes.md`）。
- **2人で使うテストで不具合が見つかった**：1人で触るだけでは出ない不具合（`04-prototype.md`）。
