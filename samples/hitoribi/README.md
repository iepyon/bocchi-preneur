# サンプル：ひとりび（新規事業の種を作るソロが、ゆるくつながる場所）

**架空のプロジェクト**でプラグインを通したシミュレーションです。登場する創業者、インタビュー、数字、見本データはすべて架空です。

本業の合間に、勤め先の新規事業の種を作っている人が、同じ立場の人たちの「行動ログ」に勇気づけられて続け、手が止まったら一度通した人に「15分相談」で声をかけられるアプリです。claude.ai のアーティファクトとして作り、共有された人だけが使います。フォロー・DM・連絡先の交換は、あえて作っていません。

| 進んだ工程 | 1 調査（宿題待ち）→ 2 企画 → 3 試作（ステップ4は本人の確認待ち）→ 4 検証（基準の記録まで） |

> **途中で戦略を作り直しています。** 最初は AI が架空の創業者として企画し、試作品まで作りました。その後、本人が戦略を見直し（対象を社内の新規事業の担い手に、匿名を価値から外す、払う人は部長）、要件・骨格・試作品を作り直しました。最初の版の成果物は削除し、いまの版だけを残しています。

## 画面と仕組み

下のタブは 行動ログ／15分相談／通知／ヒント の4つです。

| 仕組み | すること | 戦略とのつながり |
|---|---|---|
| 行動ログ | 今日の一手を40字で1つ書き、いまいるステップを選ぶ。みんなの行動ログが先に並び、自分の一手は画面下に固定。他人の一手には「応援する」 | 前段：他人がやっている雰囲気に勇気づけられて続ける |
| できた | 自分の一手を「できた」にすると、そのステップの通過記録になる | 後段：一度通した人だと分かる |
| 15分相談 | 今の一手からだけ出せる。してほしいこと（見てほしい／話を聞いてほしい／触ってほしい）・時間（15分か30分）・所属（その場で書く）を1問ずつ答える。誰でも応じられ、応じた人の名前・通過記録・「招待した経験者」の印を見て受ける | 後段：止まったら一度通した人のひとこと |
| 相談部屋 | 応じた1人と2人だけの部屋。文字のやりとりと、会議リンクやアーティファクトの共有リンク（貼る前に「伏せましたか」を確かめる）。お礼を送り、「動き出せた／まだ」を押して終える。終えると中身ごと消える | 後段、成功の指標（【発言】） |
| やめる | 自分の一手から「やめる」を選び、学びを3行書く。運営者が確かめてから公開し、みんなの行動ログに混ざって流れる。読んだ人は「頭を下げる」 | 後段：やめた経験も一度通した人の知恵になる |
| 通知 | 自分の一手・相談・学びへの反応が届く | 前段：続ける励み |
| ヒント | いまのステップと状況（一手を書く前・取り組み中・相談中・相談のあと・できた・やめた）に合う背景とヒントを1枚ずつ出す。全72枚、すべてこのリポジトリの資料から作り、出典つき | 判断の型を渡す（R7） |

相談のあとに開くと、「止まっていた一手、できましたか」が出ます（価値を感じる瞬間）。持ち主（運営者）だけに「運営」画面が出て、学びの公開、経験者の印付け、成功の指標の集計ができます。

名前は claude.ai のものを表示し、保存するのは利用者IDだけです（データの重さ：軽）。

## 試作品の触り方

アーティファクトは claude.ai 上で動きます。手元でサーバーを立てる必要はありません。

1. [04-prototype.md](docs/solo/04-prototype.md) にあるアーティファクトのリンクを開く（claude.ai にサインインしていること）
2. 試す相手には、共有メニューで「使える」（Contributor）以上の権限で共有する。「見るだけ」だと書き込めない
3. 自分で一手を書き、もう1人に「15分相談」から応じてもらう

元のファイルは [artifact/hitoribi.html](artifact/hitoribi.html) です。自分のアーティファクトとして公開し直して試すこともできます。保存の場所とアクセスのきまりは `04-prototype.md` にあります。

## このサンプルで見てほしいところ

- **想定インタビューで進んでも、ゲートは閉じない**：本人が判断を引き受けて先に進んだ記録（`decisions/02-skip-interview-gate.md`）と、ステップ1が「宿題待ち」のまま残っている state.md。
- **AI が決めた企画を、本人が作り直した**：対象・ニーズ・匿名の扱い・払う人を本人が見直し（`decisions/04-target-intrapreneur.md`、`05-what-reaches-the-manager.md`）、要件と骨格も作り直した。
- **UXの5レイヤーの対応表**（v0.9.0 で追加）：戦略のニーズから画面の部品までが1枚の表でつながっている（`02-spec.md` の末尾）。画面を選びながら出た案（共有リンクを貼る）を、先に要件に戻して R2-b として足した記録（`03-wireframe.md`）。
- **試作中の変更も、要件に戻して記録した**：「やめる」を行動にまとめた（R6）、ヒントタブを足した（R7〜R7-c）。
- **技術は本人が選んだ**：「サーバで動く必要ないかな。claude アーティファクトで十分かも」で、サーバーを立てずにアーティファクトで作った。失うもの（リンクを共有された claude.ai の利用者しか使えない）も `04-prototype.md` に書いた。この経験から、プラグインのステップ4にアーティファクトの選択肢を加えた（v0.9.1）。
- **2人を同時に動かすテストで確かめた**：保存の仕組みを手元で真似て2人を動かし、全19手順を通した（`04-prototype.md`）。claude.ai 上で2人が実際に操作する確認は、本人の宿題として残っている。
