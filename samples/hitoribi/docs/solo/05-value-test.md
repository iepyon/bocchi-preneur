## 事前に決めた基準（2026-11-15 記録）
- **人数**：20人。課題検証インタビューの相手と、個人開発者の作業会・勉強会から集める。友人知人は5人までにして、偏りを記録する
- **期間**：2週間（2027-01-04〜01-17）
- **指標**（本人が選んだもの）
  1. 継続利用：2週間後の週に、週3日以上灯をともした人の数 → **合格基準 5人以上**（撤退基準と同じ）
  2. PMFサーベイ：「ひとりびが明日なくなったらどう感じますか」に「非常に残念」→ **40%以上**
  3. お金のコミット：今回は測らない。理由「まだ集まる場所としての密度を確かめる段階。課金は作業会と組むときに測る」
- **追加で見るもの**：サインに応じた人数（助け合いが起きるか）。合否には使わない

## 本人が気にしていること
「20人だと、同じ時間に灯がともっている人が少なすぎて、ひとりではない感じが出ないかもしれない」
→ 試作品の期間中は、毎晩21〜24時を「灯の時間」として案内し、時間を寄せると決めた【推測】。
