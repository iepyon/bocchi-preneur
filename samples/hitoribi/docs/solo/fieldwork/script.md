# 課題検証インタビュー台本（10分）

対象：本業の後や独立直後に、一人で自分のサービスを作っている人。友人知人だけで埋めない。

アイデア（ひとりび）は最後まで話さない。

1. いま作っているものと、作業する時間帯を教えてください。
2. 最後に「手が止まった」のはいつでしたか。そのとき何に詰まっていましたか。
3. そのとき、実際にどうしましたか。（誰かに聞いた／検索した／AIに聞いた／やめて寝た）
4. 誰かに聞いた・聞かなかったのはなぜですか。
5. この1年で、同じ立場の人とつながるために使ったお金や時間はありますか。（コミュニティ、勉強会、もくもく会）今も続いていますか。続かなかったなら、最後に行かなくなったきっかけは何でしたか。
6. 一人で作っていて、よかったことは何ですか。

最後に：「同じように一人で作っている人を1人紹介してもらえますか」「3週間後にできる試作品を2週間使ってもらえますか」（コミット）

記録は `interview-NN.md` に、【行動】【発言】【コミット】のラベルをつけて書く。
