# 課題検証インタビュー台本（10分）

対象：本業のスキマ時間に、勤め先の新規事業の種を作っている人。自分の会社の人だけで埋めない（3社以上から）。

アイデア（ひとりび）は最後まで話さない。社外秘の中身は聞かない。「どんな段階で、何に詰まったか」だけを聞く。

1. いま新規事業の種づくりに、週に何時間くらい、どの時間帯に使っていますか。
2. 最後に「手が止まった」のはいつでしたか。そのとき、どの段階（調べる・企画・試作・上司に見せる 等）で、何に詰まっていましたか。
3. そのとき、実際にどうしましたか。（AIに聞いた／社内の誰かに聞いた／社外の知人に聞いた／見せる日を延ばした／そのまま出した）
4. 聞いた・聞かなかったのはなぜですか。社内で聞きにくい理由はありましたか。
5. この1年で、同じ立場の人とつながるために使ったお金や時間はありますか。（研修、社外の勉強会、メンタリング）会社が出しましたか、自分で出しましたか。
6. 途中経過を上司に見せたとき、何が起きましたか。

最後に：「同じように社内で新規事業の種を作っている人を1人紹介してもらえますか」「3週間後にできる試作品を2週間使ってもらえますか」（コミット）

部長（払う側）向けの追加の宿題：新規事業の予算を持つ部長2人に、「新規事業をすすめられる人を、今どう育て、どう選んでいるか。最後に選んだのはいつ、どうやって」を聞く。
