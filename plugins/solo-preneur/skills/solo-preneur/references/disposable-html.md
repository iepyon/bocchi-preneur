# 使い捨てHTMLで見比べる

文章で書かれた案を読み比べて判断するのは、非エンジニアには特に難しい。AIはWebページをほぼゼロコストで作れるので、判断のたびに専用のページを作り、見て選べるようにする。

## 作り方
- `docs/solo/compare/` に、判断ごとに1枚のHTMLファイルを作る（例：`03-home-wireframe.html`）。外部ファイルに依存しない1ファイルにする。
- 案を横並び（スマホ幅なら縦並び）にし、それぞれに短いラベルと「何が嬉しく何を失うか」を1行ずつ添える。
- 選択式にする場合は、チェックボックスで選ばせ、選んだ結果をページ上に表示して本人がコピーしてチャットに貼れるようにする。
- 作ったら、ブラウザで開く方法を本人に伝える。

## 使う場面
- ワイヤーフレームの案（ステップ3）
- 技術選定の比較（ステップ4、7）
- デザインシステムの見本、デザイン案、コピー案（ステップ8）

## 選んだあと
- 選んだ案と「なぜそれか」の一言を、該当ステップの成果物に記録する。
- 比較用HTMLは消さずに残し、成果物からリンクする。
