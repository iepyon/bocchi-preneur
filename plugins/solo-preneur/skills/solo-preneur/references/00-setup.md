# 00 はじめの準備

多くの人がつまずくのは最初の準備だけ。やることは3つ。

1. Claude Code を入れる（このプラグインが動いているなら完了済み）。
2. 空のフォルダを1つ作り、そこで Claude Code を開く。このフォルダがAIの仕事場になる。
3. 日本語で最初の指示を出す。

## 案内のしかた

- 1つずつ確認しながら進める。まとめて手順を並べない。
- エラーが出たら、画面のメッセージをそのまま貼ってもらう。推測で答えない。
- 準備ができたら、本題の前に「普段ちょっと困っていること」で小さな練習を1つ作ってもらってもよい。作れる感覚がつかめると、その後の問い詰めに耐えやすくなる。練習作品は `docs/solo/` には記録しない。
