# ソロプレナー（solo-preneur）v0.7.0

非エンジニアの経営者が、Claude Code と一緒にプロダクトを課題検証からローンチ・運用まで作り切るためのプラグイン。

**決めるのは人、作るのはAI、確かめるのは現場。**
事業判断はAIが1問ずつ問い詰めて本人の言葉で決めてもらう（GrillMe式）。顧客の課題と払う意思は、チャットではなく現場の宿題（インタビュー、事前予約）で確かめる。届けることは初日から並走させる。

## 6工程・11ステップ＋並走トラック
工程の区切りは、本人が責任を持って決める場面に置いている。

| 工程 | ステップ | 工程を出るときに本人が決めること |
|---|---|---|
| 1 調査 | 1. コンセプトと課題検証 🔴＋宿題 | 誰のどの課題か。顧客の行動で確かめられたか |
| 2 企画 | 2. 仕様設計（UXの5レイヤー＋データの重さ）🔴/🟡 | 入れるもの・入れないもの、データの重さ、AI利用の上限 |
| 3 試作 | 3. 画面設計 🟡／4. プロトタイプ実装（Web先行）🟢 | 何を作れば仮説を検証できるか |
| 4 検証 | 5. 価値検証（行動とコミットで判定）🔴＋宿題／6. 価格設計 🔴 | 進む・作り直す・やめる。いくらで売るか |
| 5 公開 | 7. 本番実装（作るAIと確かめるAIの分業）🟢／8. デザイン 🟡／9. セキュリティと公開準備 🟢/🔴／10. ローンチ 🟡 | 公開してよいか。残ったリスクを受け入れるか |
| 6 保守 | 11. 計測・運用・継続判断 🔴/🟡 | 続けるか、方向を変えるか、やめるか |

並走：届けるトラック（外販のみ）

🔴 本人の言葉でしか埋めない／🟡 AIが案を出し本人が選ぶ／🟢 AIが作り、本人は受け入れ条件を決めて確かめる

## 取り込んでいる基準
- 米国の独立開発で定番の考え方：過去の事実を聞く顧客インタビューとコミットによる判定、小さく始めて段階的に大きくする、最初から課金する、人を雇う前に自動化する、多くのアイデアはやめる前提
- 中国の独立開発で定番の考え方：公開しながら作る、無料の小ツールを入り口にする、メールリストに貯める、海外市場の論点（言語・決済・通貨・法令）
- 詳しくは `skills/solo-preneur/references/research-basis.md`

## インストール
```
/plugin marketplace add iepyon/solo-preneur
/plugin install solo-preneur@solo-preneur
```
ローカルで試すだけなら、リポジトリのルートで `claude --plugin-dir ./plugins/solo-preneur`。

## 始め方
1. プロダクト専用の空のフォルダを1つ作り、そこで Claude Code を開く（1プロダクトに1フォルダ）。
2. `/solo-preneur:start 作りたいもの` と入力する。フォルダの準備（変更履歴を残すGitの用意、記録の置き場所 `docs/solo/` の作成）はAIが確かめて行う。
3. 中断はいつでもよい。再開は同じフォルダで `/solo-preneur:start`。

## 更新
```
/plugin marketplace update solo-preneur
/plugin update solo-preneur@solo-preneur
```

## 呼び出せるスキル
入力欄で `/` から呼び出す。AIが自動で呼ぶことはない（本体の solo-preneur スキルは話しかけるだけで動く）。

| 呼び出し | 内容 |
|---|---|
| `/solo-preneur:start` | 始める／再開する |
| `/solo-preneur:next` | ゲートを確認して次へ |
| `/solo-preneur:status` | 進行状況・宿題・撤退基準を見る |
| `/solo-preneur:step <番号>` | 指定ステップへ |
| `/solo-preneur:homework [メモ]` | 現場の宿題の台本づくり／結果の記録 |
| `/solo-preneur:review` | 厳しめのコードレビュー |
| `/solo-preneur:pentest` | 自分のアプリへのペネトレーションテスト |
| `/solo-preneur:rca <症状>` | 根本原因分析（実装はしない） |

## 構成
```
.claude-plugin/      plugin.json
agents/              strict-reviewer, pentester, root-cause-analyst
skills/
  solo-preneur/      本体
    SKILL.md         思想・絶対ルール・分岐・進め方
    references/      ステップ別の詳細、interview-kit、track-distribution、research-basis
    templates/state.md
  start/ next/ status/ step/ homework/ review/ pentest/ rca/
                     / で呼び出す入口（各 SKILL.md）
```

シミュレーション記録と回帰テスト用シナリオは、利用者の環境に入らないようリポジトリ直下の `simulations/` に置いている。

## 注意
法務（規約、特商法表記、海外の法令）や税について、AIは下書きと論点整理まではするが、法的助言はしない。課金や重いデータを扱う場合は専門家への確認を勧める設計にしている。
