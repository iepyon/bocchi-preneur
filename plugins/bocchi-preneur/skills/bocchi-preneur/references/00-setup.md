# 00 はじめの準備

本題（ステップ1）の前に、作業する場所を整える。本人にやってもらうのは、プロダクト専用のフォルダで Claude Code を開くことだけ。残りはAIが確かめて、必要なら代わりに行う。

## 前提
なし。`/bocchi-preneur:start` の最初、または `docs/bocchi/state.md` がないプロジェクトで、下のどれかが欠けているときに使う。

## 確かめること（上から順に、1つずつ）

1. **プラグインが入っている**
   このスキルが動いていれば完了。別のPCで始めるときや入っていないと言われたら、次の2行を順に入力してもらう。
   ```
   /plugin marketplace add iepyon/bocchi-preneur
   /plugin install bocchi-preneur@bocchi-preneur
   ```
   入れたあと呼び出せなければ、Claude Code を開き直してもらう。

2. **プロダクト専用のフォルダで開いている**
   今いるフォルダが、ホームフォルダやデスクトップ、ほかの仕事のフォルダなら、作業を始めない。プロダクト用の空のフォルダを1つ作り（例：`~/bocchi/在庫アプリ`）、そこで Claude Code を開き直してもらう。1プロダクトに1フォルダ。このフォルダがAIの仕事場になり、成果物はすべてここに残る。

3. **変更の履歴を残せる（Git）**
   フォルダがまだ Git で管理されていなければ、「変更の履歴を自動で残す仕組みを入れます」と一言伝えて、AIが `git init` する。あわせて `.gitignore` を作り、`.env` など秘密情報のファイルを除外する。
   - 判断の記録を後から作文していないことや、いつ何を変えたかを示す証拠になる。ステップ7のレビューとステップ9の秘密情報の確認もこの履歴を見る。
   - Git が入っていなければ、入れ方を本人の環境（Mac／Windows）に合わせて1つずつ案内する。
   - GitHub などに上げるかどうかは、ここでは決めない。上げる場合も、AIが勝手に push しない。

4. **記録の置き場所を作る**
   `docs/bocchi/` と `docs/bocchi/decisions/` を作り、`templates/state.md` から `docs/bocchi/state.md` を作る。ここまで終わったら本題に入る。

## 必要になったら入れるもの（最初は入れない）
- 試作品を動かす道具（Node.js など）：ステップ4で技術を選んでから、AIが入れ方を案内する。
- 別系統のAIによるレビュー（codex CLI）：任意。入っていれば `/bocchi-preneur:review` が併用を提案する。

## 案内のしかた
- 手順をまとめて並べない。1つ終わったら次へ進む。
- 本人が操作するのは「フォルダを作って開く」「表示された確認を許可する」くらいにとどめる。コマンドを打ってもらう必要があるときは、コピーして貼るだけで済む形で1行ずつ示す。
- エラーが出たら、画面のメッセージをそのまま貼ってもらう。推測で答えない。
- 準備ができたら、本題の前に「普段ちょっと困っていること」で小さな練習を1つ作ってもらってもよい。作れる感覚がつかめると、その後の問い詰めに耐えやすくなる。練習作品は `docs/bocchi/` には記録しない。

## 作られるもの
```
<プロダクトのフォルダ>/
├── docs/bocchi/
│   ├── state.md          進み具合・出している宿題・判断の一覧
│   ├── report.md         読み手（事業責任者など）への要約。工程を通るたびに更新
│   ├── decisions/        意思決定ログ（本人が引き受けた判断を1件ずつ）
│   ├── 01-concept.md …   各ステップの成果物
│   ├── fieldwork/        宿題（インタビュー）の台本と記録
│   └── compare/          見比べ用の使い捨てHTML
└── （ステップ4以降）プロダクト本体のコード
```
やめると決めたら `docs/bocchi/` は `docs/bocchi-archive/<プロダクト名>/` に移す（SKILL.md「やめると決めたら」）。

## 中断と再開
- いつでも区切ってよい。進み具合は `docs/bocchi/state.md` に残る。
- 再開は、同じフォルダで Claude Code を開いて `/bocchi-preneur:start`。
- プラグインの更新は `/plugin marketplace update bocchi-preneur` のあと `/plugin update bocchi-preneur@bocchi-preneur`。
