## 1. ねらい

Round 1〜4 は「プラグインの手順どおりに進むか」を見てきた。Round 5 では、次の2つを同時に確かめる。

1. **動作検証**：v0.11.0 のプラグインが、ひとりびのような題材で、書いてあるとおりに動くか（ゲート、記録、矛盾の検出、再開、宿題の扱い）

## 4. シミュレーションの方法

C1 を避けるため、本人役と伴走役を分ける。

1. **伴走役**：`claude --plugin-dir ./plugins/solo-preneur` を、ペルソナごとの空のフォルダで動かす（このコンテナに `claude` CLI がある）。プラグイン以外の指示は与えない。
2. **本人役**：別のエージェントに、ペルソナの設定と隠れた事実だけを渡す。プラグインの中身は見せない。伴走役の質問に答え、AskUserQuestion には選択で答える。
3. **判定役**：会話ログと `docs/solo/` の成果物を、下の評価表で採点する。本人役・伴走役とは別のエージェントにする。
4. **部長役（P2）**：P1 の成果物だけを渡し、「任せられるか」「何が足りないか」を答えさせる。
5. **利用者（P5）**：試作品を Playwright で2人分動かし、受け入れ条件1〜3と、相談部屋の中身が当事者以外から読めるかを確かめる。既存の `artifact/test/` も実行する。

CLI を対話で動かせない場合は、Round 1〜4 と同じく SKILL.md と references に厳密に従って対話を再現する。そのときも本人役と判定役は分ける。
