# 一周目のふりかえり（2026-11-15〜2026-01-05）

同じことを繰り返さないための記録。事実はAIがまとめ、学びは本人の言葉で書く。

## 何を作ろうとしたか
- 最初の話：「コワーキングの会員どうしがゆるくつながって、困ったら15分相談できるサービス。決済までサクッと作りたい」
- 払う人：他のスペースの運営者（月額）。「会員から相談料とるのはなんか生々しい」

## 思っていたこと と 実際に起きたこと
| 本人が思っていたこと【推測】 | 実際に起きたこと【行動】 |
|---|---|
| 「会員10人に聞いたら、みんな欲しいって言ってた」 | 2週間で会員どうしの相談は1回、2回目は0人 |
| 会員どうしで相談し合う | 4回の相談のうち3回は乗り手が本人。受付メモの相談も4件すべて本人宛て |
| 乗り手は集まる | 時間を出したのは最終的に4人。乗り手の表示が3人に届いた日は0日 |
| 他のスペースのオーナーが月額で払う | 会ったオーナー5人、申込書0人。退会理由は転勤・料金・引っ越しが多かった |
| 「スマホなら書く」（AIは黒板とSlackを根拠に押し返した） | 15人中6人が2週間後も週3日以上書いた（黒板は60人中5人）。**本人の見立てが当たった** |
| 「まあ大丈夫でしょ、みんな顔見知りだし」 | 荒れはなし（報告なし）。ただし会員が運営の画面に入れる不具合があった |

## 途中で効いた判断（本人の言葉）
- 「悔しいけどBかな。実際に相談は来てるし」（最初の一段を1機能に絞った）
- 「評価は…欲しいけど我慢する」（入れないものを決めた）
- マイナンバー確認を外した（「トラブルは…ないな」）
- テスト決済の「事前予約」を証拠に数えなかった
- 「また私だけがやりたいもの作りそうだし」（作り直しを調査から始めた）

## 証拠の強さで見ると
- 一番早く分かっていたサイン：受付の相談が「全部私に直接」だったこと（2週間で4件）。本人は「受付にいるからでしょ」と読んだ
- 「いいね」「いいですよ」「年明けに考える」は、最後まで行動に変わらなかった

## 学び（本人の言葉で3行、2026-01-05）
- 分かったこと：「会員は『会員どうし』より『私』に相談したい。でも一人で働く人は、誰かに見られながら書くと続く」
- 次に持ち越すもの：「今日やることの書き込みと、受付での私の15分相談」
- 持ち越さないもの：「『みんな欲しいって言ってた』を信じて作り始めること」
