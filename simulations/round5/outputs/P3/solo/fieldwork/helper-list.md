# 宿題④ 乗り手さがし（相談に乗れる会員）

**目的**：相談に乗る側が、実際に時間を出してくれるかを確かめる。
「いいですよ」と言うだけなら【発言】、具体的な曜日と時間を決めてくれたら【コミット】（時間を差し出した）です。

## 頼み方（例）
「来月から、会員どうしで15分だけ相談できる仕組みを試します。平日の12〜15時のどこかで、週に1回15分、相談に乗ってもらえる枠を出してもらえませんか。得意な分野を1つ教えてください」

- 売り込みではなく、お願いとして頼む。
- 断られても理由をメモする（それも大事な証拠です）。

## 記録
| 日付 | 誰（イニシャル） | 得意分野 | 返事（引き受けた／保留／断った） | 曜日・時間を決めたか | 断った・保留の理由 |
|---|---|---|---|---|---|
| 〜2026-12-03 | 山本さん | 税金 | 引き受けた（試作で枠を出した） | 試作で確認 | |
| 〜2026-12-03 | 田中さん | デザイン | 引き受けた | 火曜12時【コミット】 | |
| 〜2026-12-03 | ほか3人 | 未記録 | 「いいですよ」と言っただけ【発言】 | 未決定 | |

要約：時間を差し出した乗り手は2人（山本さん、田中さん）。火木に3人という最小の密度には届いていない。
