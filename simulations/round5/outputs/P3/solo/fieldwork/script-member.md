# 宿題② 自分のスペースの会員に聞く（10分）

**目的**：「ちょっと困ったとき」に会員が実際どうしているか、相談に乗る側の負担はどうかを確かめる。
**人数**：3人以上。佐藤さん、税理士の会員さんを含める。
**注意**：オーナーのあなたが聞くと、会員は気をつかいます。意見ではなく「最後に起きたこと」だけを聞いてください。

## 相談する側に聞く（佐藤さんなど）
1. 仕事でちょっと困って、人に聞きたくなったのは最後にいつですか。何についてでしたか。
2. そのとき、どうしましたか。（誰に聞いた、調べた、諦めた）
3. 解決するまでに、どれくらい時間やお金がかかりましたか。
4. 聞いた相手に、お礼はしましたか。何をしましたか。
5. 聞かずに諦めたことはありますか。なぜ聞かなかったのですか。
6. このスペースで、他の会員さんが何の仕事をしているかを知ったのは、最後はいつ、どんなきっかけでしたか。
7. 相手が何をしている人か分かっていたから声をかけられた、ということはありましたか。最後はいつですか。
（6・7は「今日やること」の見せ合いが相談のきっかけになるかを確かめる質問です。機能の話はしないでください）

## 相談に乗る側に聞く（税理士の会員さんなど）
1. 他の会員さんから相談されたのは、最後にいつですか。どれくらいの時間でしたか。
2. そのとき、正直どう感じましたか。（嬉しかった、仕事につながった、負担だった）
3. その相談が、その後の仕事やお客さんにつながったことはありますか。
4. 相談に乗りたくないのは、どんなときですか。

## 締め
- 「同じように困っていそうな会員さんを教えてもらえますか」
- 「試作品ができたら、30分触ってもらえますか」

## 聞いてはいけない質問
- 「15分相談できるサービスがあったら使いますか」
- 「相談に乗る側として登録してくれますか」（試作品ができてから、行動で確かめます）
