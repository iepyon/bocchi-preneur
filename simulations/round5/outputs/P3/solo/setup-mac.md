## 0. この作業場所をあなたの手元に届ける：GitHub（無料）
今の作業場所はクラウドの中にあり、あなたのMacには入っていません。GitHub に「非公開の置き場所」を1つ作り、そこを経由してMacと Vercel に届けます。
1. github.com でアカウントを作る
2. 作れたら、チャットで「GitHubできた」と伝える → 置き場所の作り方を案内します（あなたの許可なしに私が送ることはしません）

## 1. Stripe（テストモードだけ使う）
1. stripe.com でアカウントを作る（事業の審査は不要。テストモードは登録直後から使える）
2. 画面右上が「テスト環境」になっていることを確かめる
3. 「開発者」→「APIキー」で「シークレットキー（sk_test_ で始まる）」があることを確かめる。**まだ写さない**

## 2. Supabase（データとメールでのログイン）
1. supabase.com でアカウントを作り、「New project」を作る（地域は Tokyo）
2. 作れたらチャットで伝える → `app/supabase/schema.sql` の貼り方を案内します

## 3. Vercel（スマホで触れるURL）
1. vercel.com で「GitHubで登録」を選ぶ
2. 作れたらチャットで伝える → つなぎ方を案内します

Claude のデスクトップアプリ（Mac）を開き、Claude Code でこのプロダクト用のフォルダを開く。
許可の確認が出たら「許可」を押す。ここで私が試作を動かし、受け入れ条件①〜③を確かめます。
