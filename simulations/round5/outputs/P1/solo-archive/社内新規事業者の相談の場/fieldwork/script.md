# 質問台本：社内の新規事業担当者（10分）

確かめたいこと（相手には言わない）：
評価する立場ではなく、同じ壁を越えた人に、気軽に聞けなくて困っているか【推測】

## 始める前に
- 「アイデアの評価をお願いしたいのではなく、新規事業を進める中での実際の経験を教えてほしい」と伝える。
- 「聞いた内容は、個人が分かる形で部長には伝えません」と伝える（上司に見られる心配があると本音が出ない）。
- 録音してよいか、必ず確認する。
- 自分の企画（相談の場）の話は、最後までしない。

## 質問
1. 「今、どんな新規事業テーマを担当していますか。いつからですか」
2. 「最後に、企画が止まったり、進め方が分からなくなったりしたのはいつですか。そのとき何が起きていましたか」
3. 「そのとき、どうやって乗り切りましたか。誰かに聞きましたか」
   - 聞いた → 「誰に聞きましたか。その人を選んだのはなぜですか。どうなりましたか」
   - 聞かなかった → 「聞かなかったのは、どうしてですか」
4. 「止まっていたのは、どれくらいの期間でしたか」
5. 「本、研修、社外の勉強会、AIなど、ほかに試したことはありますか。続かなかったものがあれば、なぜですか」
6. 「新規事業を進めていて、一番しんどいのはどの部分ですか」

## 締め（次の一歩をお願いする）
- 「同じように新規事業をやっていて、話を聞かせてくれそうな人を紹介してもらえますか」
- 「何か形にできたら、30分ほど触ってもらえますか」

## やってはいけない質問
- 「新規事業の担当者同士で相談できる場があったら使いますか」
- 「こういうアイデアなんですが、どう思いますか」
- 「上司に聞きにくいですよね？」（答えを誘導してしまう）
