# 宿題：部長に「期待されていること」を確かめる（10分）

目的：社内ツール（a）／外販（b）／社内で試して外販も考える（c）を決める材料を集める。
アイデアの説明や「どう思いますか」はしない。部長が**これまでに見たこと、実際に起きたこと**を聞く。

## 質問台本
1. 「このテーマを私に任せようと思ったのは、何かきっかけになった出来事があったからですか。最後にそれを感じたのはいつ、どんな場面でしたか」
2. 「社内で新規事業をやっている人が、相談相手がいなくて困っていた場面を、実際に見たことはありますか。そのとき、その人はどうしていましたか」
3. 「半年後に、何がどうなっていたら『やってよかった』と言えますか」（社内の担当者が楽になること／会社の新しい売上になること、のどちらに近いかを聞き取る）
4. 「これを社外に出す（他社にも使ってもらう、売る）可能性は、今の時点で考えていますか。それを決めるのは誰ですか」
5. 「使ってよいお金や人の手、それから区切りの時期について、決まっていることはありますか」

締め：「社内で新規事業をやっている人を、2〜3人紹介してもらえますか」

## やってはいけない質問
- 「相談の場を作ったら、みんな使うと思いますか」
- 「こういうアイデアなんですが、どう思いますか」

## メモのとり方
- 部長の言葉をそのままメモしてください。要約はあとで一緒にやります。
- 報告はメモの貼り付けで大丈夫です。
