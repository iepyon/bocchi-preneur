# 質問台本：部長への追加の聞き取り（5〜10分）

対象：総務部長（2回目）と、研修予算を使ったことがある別の部長（人事の同期から部署名を聞く）
確かめたいこと（相手には言わない）：
人事や上から育成の効果を聞かれたときに、説明できずに困った出来事があるか。

## 質問
1. 「部下の育成にかけたお金や時間について、人事や上の方から効果を聞かれたことはありますか。最後はいつでしたか」
2. 「そのとき、何を見せて、どう説明しましたか」
3. 「その説明で、相手は納得しましたか。何か追加で聞かれたり、言われたりしましたか」
4. 「説明のために、何か準備や記録をしていますか。それにどれくらい時間をかけていますか」

初めて話す部長には、先に `script-manager.md` の質問3（育成のために実際にやったこと）を聞く。

## 締め
- 「何か形にできたら、15分ほど見ていただけますか」

## やってはいけない質問
- 「育成の効果を説明するのは大変じゃないですか」
- 「効果が見える仕組みがあったら使いますか」

## 判定のしかた（撤退基準の部長の側）
効果を聞かれて、アンケート結果くらいしか出せなかったことが**実際にあった**ら当てはまる。「聞かれたら困ると思う」は【発言】なので数えない。2人中2人で当てはまる。
