# まとめて聞くこと（2回目）：3人に1〜2問ずつ（各5分）

## 1. 人事の同期
確かめたいこと：失っているコストの推測（予算削減・約150万円）を事実にする。
1. 「来年度の研修予算について、見直しや削減の話は実際に出ていますか。出ているなら、どの場で、どんな話ですか」
2. 「去年、研修予算を使った9部署の研修費は、合計でいくらくらいですか」（合計額だけ。部署別・個人別は不要）

## 2. 企画部長（自分の部長）
確かめたいこと：既存の手段（研修会社の効果測定）で足りるか。
3. 「去年2人を出した研修会社に、受講後アンケート以外の効果測定（数か月後の行動の変化を見るなど）のオプションはありましたか」
4. 「あったなら、選ばなかったのはなぜですか。費用はいくらでしたか。部長の手間はどれくらいかかるものでしたか」
   - 部長が覚えていなければ、研修会社の名前と研修名を教えてもらう（AIが公開されている情報を調べる）

## 3. 営業部長（または報告書を書いた課長）
確かめたいこと：書き直しにかかった時間（失っているコスト）。
5. 「去年の秋の人事からの問い合わせに対して、報告書の書き直しに、全部で何時間くらいかかりましたか。誰が書きましたか」

## 判定のしかた（作らない選択肢）
本人の線（2027-01-12）：「研修のあとに部下の企画書が実際にどう変わったか（前と後）が、1人あたり2万円以下の追加費用で、部長の手間がほとんどかからずにできるなら、作らずにそれを使う」
「部長の手間がほとんどかからず」＝部下1人あたり30分以内（2027-01-12 本人決定）
→ 研修会社のオプションが「前と後の変化が分かる」「1人あたり2万円以下」「部長の手間が部下1人あたり30分以内」の3つをすべて満たすなら、作らずにそれを使うよう部長に勧める。

## やってはいけない質問
- 「効果が測れる仕組みがあったら使いますか」
- 「書き直し、大変でしたよね？」
