# 質問台本：新規事業の担当者を部下に持つ部長（10分）

確かめたいこと（相手には言わない）：
「新規事業の担当者を部下に持つ部長が、中期計画で各部から新規事業テーマを出すときに、＿＿＿で困っている」の＿＿＿に入るものを、部長の過去の行動から見つける。

## 始める前に
- 「アイデアの評価ではなく、部下の新規事業を見る立場としての実際の経験を教えてほしい」と伝える。
- 録音してよいか確認する。
- 自分のアイデアの話は最後までしない。

## 質問
1. 「最後に、部下が出した新規事業の企画を差し戻したり、コメントしたりしたのはいつですか。そのとき、何をどう伝えましたか」
2. 「そのあと、その部下は企画をどう直してきましたか。伝えたことが伝わったかどうかは、どこで分かりましたか」
3. 「この1年で、部下を育てるために実際にやったことは何ですか。時間やお金はどれくらい使いましたか」
   - 出てこなければ順に確認する（撤退基準の判定用）：
     - 「新規事業の担当の部下を、研修や講座に出したことはありますか。いつ、何に出しましたか」
     - 「ほかの人（先輩や別部署の人など）に、その部下に教えるよう頼んだことはありますか」
     - 「会議や書類のチェックとは別に、育成のための1対1の時間はとっていますか。直近ではいつで、どれくらいの頻度ですか」
4. 「研修や外部の講座を使ったことはありますか。その効果を、上の人にどう説明しましたか」
5. 「中期計画で新規事業テーマを出すとき、一番手間がかかったのはどの部分ですか」

## 締め
- 「同じように新規事業の担当者を部下に持つ部長を、紹介していただけますか」
- 「何か形にできたら、15分ほど見ていただけますか」

## やってはいけない質問
- 「部下が育たなくて困っていませんか」
- 「こういう仕組みがあったら予算を出しますか」

## 判定のしかた（撤退基準）
1人ずつ、この1年で次のどれかに【行動】として当てはまるかを見る。
- 部下を研修に出した（お金）
- 誰かに部下へ教えさせた（時間）
- 会議や書類チェックとは別に、育成のためだけに1対1の時間を月1回以上とっていた（時間）
「やろうと思っている」「大事だと思う」は【発言】なので数えない。3人中2人以上で続ける。
