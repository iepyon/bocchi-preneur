## 触り方（本人の手元）
1. `npm install`
2. `supabase start`（Docker が必要）→ 表示された URL と anon キーを `.env.local` に入れる（`.env.example` 参照）
3. `npm run dev` → ブラウザを2つ開き、右上の「表示中」をAさん・Bさんに分けて操作
   - 同じブラウザのタブ2つだと、選んだ人が共有されて同じ人になる。別のブラウザか、シークレットウィンドウで開く
4. 起動設定（`supabase/config.toml`）は本人の手元の `supabase init` で作られたもの。リポジトリに入れておくと別のPCでもそのまま `supabase start` できる
