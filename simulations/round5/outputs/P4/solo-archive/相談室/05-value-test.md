# ステップ5 価値検証（社内試用）

## 事前に決めた基準（結果を見る前に記録）
- 対象者：社内の新規事業担当 約10人。【注】本来の対象（社内に相談相手がいない人）とは異なり、互いが同じ会社の同僚。本人は弱さを承知のうえで「社内での予行演習」と位置づけている
- 期間：リンク送付から2週間（2026-11-29ごろ送付）
- 指標1（合格ライン）：10人中5人が、自分の悩みを書き込む（2026-11-15決定「じゃあ半分、5人で」）
- 指標2：1週目と2週目の両方で書き込んだ（相談か返事）人の数（本人「①B」）。合格ラインは未設定
- 参考として記録：返事の数、返事を書いた人数、15分の申し込み数と成立数
- 密度を作る工夫：特になし（本人「②C」「返事まで自分でやる時間ないです」）。返事がつかなかった相談の数と、返事がつくまでの時間を記録し、密度の問題か価値の問題かを分けて見る
- 本人の書き込み：しない（本人「③C」）。本人は集計に含まれない
- お金のコミット：測らない（理由：社内の予行演習のため）
- 撤退基準：5人に届かなければ作り直す。作り直しは1回まで。作り直した版でも届かなければやめる（本人「Bかな」「……じゃあAで。1回まで」）

## 数え方
- 人数は、書き込みについている「匿名の印」の種類で数える（誰が書いたかは本人にも分からない）
- 指標2と密度は、保存データの書き込み日時から、終了後にAIが集計する（公開ページのリンクが必要）

## 試用期間の外で分かったこと
- 中間報告で部長に「で、誰が困ってるの？」と聞かれ、答えられなかった（本人「言ってなかったけど」）。ステップ1の課題検証をスキップしたときに伝えたリスクが、実際に起きた

## 結果を見た本人の読み（判断の前）
「正直、成立した15分も同期どうしだし、自分が助かったのも同期なんですよね。知らない人に相談する場、ってのがそもそもズレてる気もする。でも作り直しても、また部長に『誰が困ってるの』って聞かれたら同じじゃないですか？ AかBか迷ってます」
- 根拠：15分の成立1件が同期どうし【行動：社内同僚1件】、本人が半年前に同期に相談して助かった【行動：本人1件】
- 要約：「知らない人に相談する場」というコンセプトの前提を、本人が疑い始めている

## 本人の判断（進む／作り直す／やめる）と理由
- 判断：**やめる**（2026-12-13ごろ）
- 本人の言葉：「……Bにします。掲示板の形にこだわる理由はもうないし、作り直しって言っても中身ほぼ別物になりそうなんで」
- 撤退基準との照合：指標1が未達（4人／5人）。事前の基準は「作り直す（1回まで）」だったが、作り直しの中身が別物になるため、作り直しではなく「やめて新しいアイデアとして始める」を選んだ。基準からの変更として記録する
- 次の課題検証（5人に聞く）について：「それはまだ約束できないです」→ 宿題は出していない
